# v4.0.0 上游合并

将上游 `a4b4445141eb7d3b3e99eada9292775383bfc44e` 合入已验证的 `429711be`。共同基线为 `fec97590`。沿用 [v3.18.2 合并规格](upstream-v3.18.2-merge.md) 和[产品配置](product-configuration.md)。

## 产品与验收规则

- 合入上游交互、CLI、桌面和工具运行时实现。桌面预装工具由 Main 调度，预装进程管理该产品用户目录下各发布身份的安装记录与可执行入口。按用户选择，五种预装工具默认使用上游 CDN，保留专用镜像覆盖。应用更新和市场服务继续使用已有产品来源。
- Skill、MCP、工作区插件、工作流、凭据恢复、浏览器状态、反馈和分享沿用用户与项目隔离开关及显式路径优先级。设置页遵守产品的登录策略和自定义模型导航，官方 Provider 的草稿迁移只适用于其协议规定的模型。
- 保留内置插件资源与产品参数注入。设计插件通过上游工具协议调用可用的图片插件。两个仓库独立构建。
- CLI 持有会话事实与子任务活动，Host 保持任务组织和租约。验证现有桌面 continuous 和手机 replayable 的共享状态投影，分别记录夹具与实机证据。
- 合并前核对 101 个两边都改过的路径。运行根类型和 Lint、架构、schema、CLI 和工程定向回归，复核有变化的 React Hooks 并执行运行时验证。使用已检入的上游回归用例和数据副本。

```text
产品配置 → Host / CLI 的目录与插件声明 → 会话运行时 → 快照或增量 → 对话状态栏
Main → 预装进程 → 按发布身份的安装目录与 bin → Host 启动的 Agent
模型目录和账号能力 → 当前 Provider 的草稿迁移判定 → 草稿选择
```

## 整合结果

上游改动涉及 2,209 个文件，101 个路径也有 fork 定制，Git 报告 22 个冲突文件。中英文 README 标注新基线和预装资源来源。默认模型设置保留 Default Plan 占位、自定义供应商和既有模板排序。产品配置、默认配置与两份内置模型清单与第一父提交相同。

- 预装工具沿用上游完整资源清单、默认 CDN、下载校验及每工具开关。资源目录使用现有产品用户根。桌面测试共用同一产品目录解析规则。
- 实时 Skill 监听、项目 MCP 配置回退、默认无头浏览器登录态文件和同机共享凭据按对应用户或项目隔离开关取路径。远程 Source Server 继续使用原服务安装布局。资料目录切换继续先复制、由 Main 登记目标密钥、再保存新路径。
- Sites 部署脚本搬进技能目录后，其产品绑定文件解析模块随技能一起分发。构建、清理、Turbo 缓存还原和单文件可执行程序的种子清单覆盖该模块。新增回归复制整个技能到临时目录后运行真实 CLI，并验证项目隔离开关两种取值。
- 崩溃恢复弹窗、预装与分享提示采用配置的产品名。Node REPL 采用新版 API，已跟踪的类型声明与构建产物一致。保留会话遥测协议实现和现有遥测策略，依照仓库 App 单测退役规则省去上游新加的 shared 遥测业务单测及其专用 Vitest 入口。
