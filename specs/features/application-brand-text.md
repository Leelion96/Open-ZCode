# 通用文案主体调整

## 范围与规则

- 通用错误、运行提示、内部提示词和能力说明按语义省去不必要的 ZCode 主体；需要说明对象时使用会话、运行时、应用、Agent 等通用称谓。
- 原有 Agent 术语与权限指引保留；不通过全文字符串替换改写用户输入、第三方内容或外部 API 原文。
- 中英文同步调整预置 MCP 配额、运行组件下载、3.x 客户端试用和任务执行期间的操作说明；保留原业务条件、消息 ID 和业务占位符。
- 本地指南名称、说明与示例使用通用文案；名称兜底只按完整官方插件 ID 判断，外部 listing 优先，第三方同名插件保持原名。
- 自有浏览器文档直接说明 CLI、当前进程、运行时和后端；保留技术 API、命令与生命周期含义。
- 主 Agent 身份、应用品牌展示、名称配置、资料隔离、服务地址、构建与分发不属于本次提交。

## 所有者与兼容

文字仍由原消费点生成，不新增文案转换层、业务状态、队列或协议字段。错误文本改变时同步原有判断；协议错误类型、超时事件和 pending 清理保持不变。旧停止记录仍识别为 cancelled，泛化 Session failed 包装仍优先展示真实原因。

```text
原错误生成 → 原有转发 → UI 错误筛选 / 回收判断
新旧停止记录 → 原有 transcript hydration → cancelled
外部 API / listing / 用户内容 → 原文
```

## 验收

- 在原名称配置下独立构建，不依赖新品牌常量或新构建注入。
- 协议超时、关闭、dispose 后 pending 清理与错误类型正确；新旧取消标记恢复为 cancelled，第三方错误原样保留。
- Guide 本地兜底与外部 listing、第三方同名插件分别验证；中英字典只包含本次通用修改，业务占位符不变。
- 使用已有配置/隔离测试及语义回归，运行类型、Lint 和架构检查；界面由用户验收。
