# 06 — 生命周期操作失败但连接仍在时，设备显示“连接失败”

Status: needs-triage

## Parent

[01 — 在设备卡上停止和重启远端服务](01-stop-restart-remote-service.md)

## Problem

更新或重启在远端旧进程退出前失败（例如远端服务无响应）时，在线连接仍然可用。Host 沿用更新失败的收口，把状态恢复为
`online` 并带上错误。五态展示模型把“非 offline / absent 且带错误”投影为“连接失败”
（`packages/ui/src/lib/remoteConnectionPresentation.ts` 的 failed 分支），设备卡因此显示“连接失败”，但连接其实可用，
也不会进入自动恢复。

- 更新失败：存量行为，本功能之前已存在。
- 重启失败：#04 沿用同一收口，表现相同。

## 待定

- 操作失败但连接仍在时，设备应显示什么；错误只经 toast、操作日志与失败详情呈现，还是保留在连接状态上。
- 更新与重启是否统一处理。
