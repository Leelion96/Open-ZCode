# 12: 子智能体依赖提示

Status: done

**Parent:** [数据同步：把本机配置推送到远端设备](../../remote/data-sync.md)

**What to build:** 在子智能体分类中，如果某个子智能体引用的 MCP 服务器或技能在本机存在、在远端不存在，行内说明会提示缺失项，例如「远端缺少 MCP：github」「远端缺少技能：code-review」。用户可以据此先在同一个弹窗里推送依赖。提示不阻止推送；依赖推送完成后，提示随重新比较自动消失。

**Blocked by:** [06: MCP 服务器分类](06-mcp-category.md)、[09: 子智能体分类与新同步通道](09-subagent-category-sync-channel.md)

## Acceptance criteria

- [x] 依赖关系取自子智能体的 `mcpServers` 和 `skills` 字段，只认运行时支持的字符串名称形式；对象形式不作为依赖。
- [x] 两端是否存在，取自同一弹窗中 MCP 和技能分类的本机与目标端列表，不新增 RPC 请求。按两个分类各自的对齐规则匹配，即名称转小写。
- [x] 只有本机对应分类列表中有该依赖、且目标端列表中没有时才提示；内置技能、插件提供的技能 / MCP 不提示。某分类的本机或目标端列表未就绪、加载失败时，不判断该类依赖。
- [x] 缺失项写在行内说明中，多个缺失项合并为一行显示；行状态和默认勾选不受影响。
- [x] MCP 或技能推送完成后，子智能体分类基于最新的目标端列表重新计算提示。
- [x] 中英文文案齐全。
- [x] 先补测试再改代码。

## Verification

- Seam ②：注入带依赖的子智能体与不同的本机 / 目标端 MCP / 技能列表，断言提示文案；本机列表中没有的依赖不提示；推送依赖后提示消失；提示不影响勾选。

## Comments

- 2026-10-17 补充修改 12b（decisions.md 第 21 条）：原实现只看目标端列表，内置技能、插件提供的技能 / MCP 被误报为「远端缺少」。改为本机列表有、远端列表没有才提示；本机或远端列表未就绪时不判断该类。
