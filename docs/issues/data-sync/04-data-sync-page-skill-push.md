# 04: Tracer：数据同步页与技能推送

Status: done

**Parent:** [数据同步：把本机配置推送到远端设备](../../remote/data-sync.md)

**What to build:**

1. 桌面用户在「设置 → 数据与统计 → 数据同步」中看到在线的 SSH、WSL、Docker 设备，每台显示上次同步状态（尚未同步 / 某时间已同步 / 上次同步失败）。
2. 点「同步」打开该设备的数据同步弹窗。左栏只有「概览」和「技能」，其他分类在各自的票中加入；会话、记忆不出现，也没有推送 / 拉取分段控件。
3. 概览的技能行显示本机数量、远端数量和「N 项变更 / 已一致」，带三态分类勾选框和「推送全部」。
4. 技能分类按状态列出本机技能，用户勾选后推送到远端，支持新建和更新。推送结果写回设备同步状态，设备行随即更新。

这是第一条贯穿状态存储、服务、Renderer 和 E2E 的路径。后续分类都接在本票建立的同步服务形状和 Renderer 适配层上。

**Blocked by:** [01: config.json 写入加固](01-harden-user-config-writers.md)、[03: 本机 Docker 远端 E2E runner](03-local-docker-remote-e2e-runner.md)

```text
设置 → 数据同步 → 设备行 [同步]
  └─ 弹窗：概览（技能行） / 技能
       list ×2 → contentHashes（只对两端都有、签名相同的项）→ compare
       → 勾选 → export → checkWriteAccess → import(createOnly | overwrite, expectedTargetHash)
       → 写入设备同步状态 → 刷新远端技能列表 → 重新比较
```

## Acceptance criteria

- [x] 「数据同步」是「数据与统计」分组的第一项。Web 与手机不显示，直接访问时的跳转方式与「远程设备」页一致。
- [x] 设备来自本机 Source Server 管理快照，本票只显示在线设备（离线、连接中、失败等状态在 05，已由 05 放开）。设备行显示状态点、名称、传输方式、目标地址和上次同步状态。
- [x] 弹窗外观遵循设计稿：迁移向导外壳、左侧分类导航、标题下的设备行、固定的底部操作栏；窄窗口下分类变为顶部横向滚动标签。
- [x] 远端一侧使用该设备的 source-settings attachment，不打开 workspace tab，也不新建 Host、连接或 Agent。
- [x] 技能服务按 spec 的统一形状实现 `list`、`contentHashes`、`checkWriteAccess`、`export`、`import`（每项指定 `createOnly` 或 `overwrite`，带 `expectedTargetHash`）。Renderer 适配层按分类分派。旧的「列出远端状态」接口暂时保留给旧弹窗使用，到 14 删除（14 已删除）。
- [x] 比较为 Renderer 纯函数：技能对齐 key 是归一化的 name；版本只取商店安装元数据，两端都有时才比较。行状态、说明文案、排序和默认勾选按 spec 的状态表实现；黄色「差异」项可以手动勾选；超出大小上限、目录内含软链、目标为软链或位于 `~/.agents` 的项显示为不能同步，并写明原因。
- [x] 5 条性能措施全部实现：只为两端都有的项计算哈希；先做文件数 + 字节预检；超限项不计算；两端并行，概览逐行加载；弹窗内缓存，推送后只重算受影响的项。
- [x] 更新时先解压到同盘临时目录，原目录改名为备份，再换上新目录；成功后删除备份，失败则还原。目标在列表加载后发生变化时返回 conflict，提示「远端已变化，请刷新后重试」，不写入。
- [x] 启用状态：新建项带上来源的启用状态，路径键换算为目标端路径；更新项保留目标端的启用状态。
- [x] 概览分类勾选框为三态，勾选即选中全部可勾选项，与分类页互相同步。「推送全部」只执行有勾选项的分类，按钮依次显示推送全部、全部同步中…、已全部同步。
- [x] 分类底部显示「将同步 N 项」或「未选择任何内容」；「取消选择」和「推送技能」按状态启用或禁用；推送中显示「同步中…」，完成后显示「再次同步」。部分失败时，失败项在行内显示原因，底部汇总失败数。
- [x] 推送中禁止关闭弹窗，弹窗没有全局取消。设备断线后弹窗显示离线并禁用操作，丢弃旧 generation 的迟到结果；设备重新上线后重新加载列表。
- [x] 每次推送结束，本机 Host 按 sourceServerId 写入 `lastSyncAt` 和 `lastResult`（success / partial / failed）。该状态不写入 `setting.json`，不修改 Source 设备记录的 schema；设备行只从这里读取。
- [x] 推送后刷新远端技能列表，并按现有逻辑使草稿会话失效。
- [x] 中英文文案使用 `remoteSync.*` 命名空间；遵循 `DESIGN.md`，深浅主题下标签都清晰可读。
- [x] 先补测试再改代码；相关规格随实现更新。
