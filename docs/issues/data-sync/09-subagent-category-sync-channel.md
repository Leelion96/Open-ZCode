# 09: 子智能体分类与新同步通道

Status: done

**Parent:** [数据同步：把本机配置推送到远端设备](../../remote/data-sync.md)

**What to build:** 用户可以在数据同步弹窗中把本机的 User 级子智能体推送到远端，并在概览中看到子智能体一行。子智能体按名称对齐，按原文件推送，所以模型、工具、技能、记忆等全部字段原样保留。本票同时新增一个同步通道，统一覆盖子智能体、命令、钩子三类，供 10、11 复用。

**Blocked by:** [04: Tracer：数据同步页与技能推送](04-data-sync-page-skill-push.md)

## Acceptance criteria

- [x] 新同步通道按 spec 的统一形状实现，按 category 区分子智能体、命令、钩子，在本机和远端 Host 都注册。
- [x] 新通道加入远程 workspace RPC 合同、source-settings 服务集合和远端 bundle 部署检查标记；**不加入**手机远控白名单。
- [x] 来源和目标各自按本端的存储根目录解析用户子智能体目录，两端的存储目录配置可以不同。
- [x] 对齐 key 为 name（转小写），不使用文件名；同步时原样复制文件字节，不经过表单保存接口。
- [x] 哈希在本端完成 markdown 迁移之后计算，避免迁移造成误判。
- [x] 禁用状态：新建项带上来源的禁用状态，更新项保留目标端的禁用状态。内置智能体和插件智能体的模型覆盖不同步。
- [x] 更新为原子替换，替换的是目标端该 name 对应的实际文件；`expectedTargetHash` 冲突时不写入。
- [x] 推送后刷新远端的子智能体列表。
- [x] 中英文文案齐全。
- [x] 先补测试再改代码。

## Verification

- Seam ①：两个临时 HOME，且存储目录配置不同；未知 frontmatter 字段在推送后保留；禁用状态规则；冲突处理。
- Host 单测：新通道出现在 RPC 合同和 source-settings 服务集合中，手机 attachment 调用时被拒绝。
- Seam ③：推送一个带模型和工具配置的子智能体，在远端断言文件字节与本机一致。
