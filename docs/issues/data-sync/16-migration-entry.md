# 16: 迁移入口移到数据同步页

Status: done

**Parent:** [数据同步：把本机配置推送到远端设备](../../remote/data-sync.md)

**What to build:** 数据同步页顶部的操作行只有一个「迁移」按钮，点击后直接进入迁移向导的第一步「会话」，用于从其他 AI 工具导入本机。设置侧栏底部单独的 Onboarding 入口删除。迁移向导的欢迎页删除。迁移相关入口都直接进入向导第一步「会话」：数据同步页的「迁移」按钮，以及首次启动时自动检测到可迁移内容后的打开。第一步左下角的按钮为「取消」，点击关闭弹窗。「通用」页的「打开引导」不改，仍打开职业引导。首次启动的职业引导流程不变。

**Blocked by:** [04: Tracer：数据同步页与技能推送](04-data-sync-page-skill-push.md)

## Acceptance criteria

- [x] 数据同步页顶部操作行右对齐，只有「迁移」按钮；「导出本地 / 导入本地」不显示。
- [x] 「迁移」打开迁移向导，直接进入「会话」步骤。
- [x] 删除设置侧栏的 Onboarding 入口及其用户行为埋点调用。
- [x] 「通用」页的「打开引导」及其描述文案不改，仍打开职业引导。
- [x] 首次启动自动检测到可迁移内容时，直接打开迁移向导的「会话」步骤，不经过欢迎页。
- [x] 删除欢迎页及其专用视觉组件和文案；引导弹窗不再有欢迎 / 向导两种视图，各步骤的启用条件不再依赖视图状态。
- [x] 向导第一步的「取消」关闭弹窗；其他步骤的「上一步 / 下一步 / 开始迁移 / 完成」行为不变。
- [x] 首次启动的职业引导流程不变。
- [x] 删除不再使用的中英文文案键；新增文案中英文齐全。
- [x] 先补测试再改代码；如有 onboarding 相关规格，同步更新。

## Verification

- 单测：侧栏不再出现 Onboarding 入口；「迁移」按钮和首次启动自动检测都进入「会话」步骤；第一步「取消」关闭弹窗；「通用」页的「打开引导」仍打开职业引导。
- Seam ③：设置 → 数据同步 → 迁移，断言进入向导第一步；点「取消」后弹窗关闭。
